# Fotos de cada cumpleaños

Sube aquí una foto por cada año, nombrada con el año exacto:

```
2026.jpg
2027.jpg
2028.jpg
...
```

Formatos admitidos: `.jpg`, `.jpeg`, `.png`, `.webp`.

Si para un año concreto todavía no has subido foto, la postal de ese año
mostrará automáticamente un aviso con el nombre de archivo exacto que
espera — no rompe el diseño, simplemente te lo recuerda.
